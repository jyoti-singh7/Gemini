A responsive and interactive Gemini Clone built using React.js, mimicking the UI of Google’s Gemini chatbot. This project focuses on frontend design, smooth UX, and simulates AI conversation behavior.

🚀 FEATURES:-

 -Chat interface for user and AI messages
 -Responsive design optimized for all screen sizes
 -Smooth scrolling and message updates
 -Clean UI inspired by Gemini (Google AI)

 
 🛠 TECH STACK:-
 -React.js (Functional Components & Hooks)
 -Vite
 -Javascript

 📚 HOW IT WORKS:-

-The user types a message in the input field.
-On submit, the message is added to the chat window.
-The input is sent to an AI API .
-The API response is fetched and displayed as the AI's reply in the chat.
-Messages continue to appear in a conversational format.
